locale: zh
title: JSON 格式化 / 校验
description: 在浏览器里格式化并校验 JSON。不会上传任何内容。
intro: 把 JSON 粘贴进来，在本地格式化并校验。无效文档会显示错误；数据不会离开本页。
howTo:
  - 在输入框粘贴或输入 JSON。
  - 查看格式化结果或校验错误。
  - 用复制按钮拷贝结果。
faq:
  - question: 这个 JSON 工具会上传我的数据吗？
    answer: 不会。格式化在浏览器里完成，不会上传。
  - question: 为什么我的 JSON 无效？
    answer: JSON 要求键名用双引号、不能有尾随逗号、不能有注释。工具会提示「无效的 JSON」，不会尝试自动修复。
  - question: 可以在这里压缩 JSON 吗？
    answer: 当前版本用两个空格做美化打印。不包含压缩功能。
