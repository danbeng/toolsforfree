---
locale: zh
title: Markdown 预览
description: 在浏览器里预览 GitHub 风格 Markdown。不会上传任何内容。
intro: 粘贴 Markdown。预览和消毒在本地完成。远程图片会被拦截。
howTo:
  - 把 Markdown 粘贴到源码面板。
  - 预览会随输入更新。格式化在浏览器本地运行。
  - 用复制按钮拷贝消毒后的 HTML。
faq:
  - question: Markdown 会上传吗？
    answer: 不会。解析和消毒都在浏览器里完成，不会上传任何内容。
  - question: 会显示远程图片吗？
    answer: 不会。远程图片会被拦截，预览不会发起网络请求。data URI 也会被去掉。
  - question: 这是所见即所得编辑器吗？
    answer: 不是。这是预览工具。左侧粘贴 Markdown，不能直接编辑渲染后的 HTML。
