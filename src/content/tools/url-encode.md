title: URL Encode / Decode
description: Percent-encode or decode URL components in your browser. Nothing is uploaded.
intro: Convert text to percent-encoded URL components or decode them locally. Choose encode or decode explicitly; nothing leaves this page.
howTo:
  - Choose Encode or Decode.
  - Paste text or a percent-encoded string into the input.
  - Copy the result with the Copy button.
faq:
  - question: Is my data uploaded?
    answer: No. Encoding and decoding run in your browser. Nothing is uploaded.
  - question: What is the difference between encode and decode?
    answer: Encode percent-encodes a URL component (spaces become %20). Decode turns percent-encoded text back. Use the mode toggle; the tool does not guess.
  - question: Why do I see Invalid URL encoding?
    answer: Decode only accepts valid percent-encoding. A lone %, truncated sequences, or invalid hex such as %zz produce Invalid URL encoding.
