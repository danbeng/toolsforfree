<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Visitor browser → documentElement | Untrusted localStorage string and matchMedia result become data-theme on html |
| Visitor click → storage | Toggle writes the theme key; must not persist attacker-controlled markup |
| Theme scripts → page JS | Inline scripts run in page origin; must not eval or inject HTML |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Tampering | ThemeInit.astro / ThemeToggle.astro | high | mitigate | Allowlist light or dark before setAttribute; never assign storage into HTML; literals only (ASVS V5) |
| T-07-02 | Information disclosure | Theme persistence | medium | mitigate | Origin-scoped web storage only; no cookies; value is not a secret |
| T-07-03 | Denial of service | ThemeInit.astro storage get | medium | mitigate | try/catch around storage; still setAttribute from matchMedia so the page paints |
| T-07-04 | Elevation of privilege | ThemeInit inline script | low | accept | No CSP in repo today; keep the IIFE tiny with no eval; future CSP would allow this hash or a nonce |
| T-07-05 | Repudiation | Theme preference | low | accept | Preference is not an audit event; no accounts |
| T-07-06 | Spoofing | ThemeToggle button | low | accept | Control is not an auth surface; aria-label is static English chrome |
| T-07-SC | Tampering | npm/pip/cargo installs | high | accept | No package-manager install tasks this phase; do not add Playwright or icon packs |

High-severity T-07-01 is mitigated in ThemeInit and ThemeToggle (block-on high). T-07-SC has no install to perform.
</threat_model>
