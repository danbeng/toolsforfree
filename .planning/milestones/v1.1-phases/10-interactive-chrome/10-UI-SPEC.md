## Typography

Exactly four sizes, two weights. This phase does not restyle page type; it inherits Phase 7 / HEAD. HEAD `.nav a.logo` is `font-weight: 650` — **leave it**; do not “normalize” to 600.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 14px | 400 | 1.2 |
| Body | 16px | 400 | 1.5 |
| Code | 14px | 400 | 1.5 |
| Heading | 20px | 600 | 1.2 |

Where they apply this phase:

- **Body 16px / 400 / 1.5** — `.faq details > p` (answer). `.tool-panel button` inherits 16px / 400 (do not set a new size on the button).
- **Label 14px / 400 / 1.2** — unused this phase. Do not add overlay eyebrows, “Output” bars, or FAQ captions.
- **Code 14px / 400 / 1.5** — existing `.tool-output` / form controls; inherit only.
- **Heading 20px / 600 / 1.2** — existing page `h2` including the FAQ heading; inherit only. Do **not** restyle `h2` font-size this phase.

`.faq summary` is **16px / 600 / 1.2** (body size + heading weight). Browser default `summary` is 400 — set `font-weight: 600` so questions read as labels without a third weight. Do not use 20px on summaries.

Weights allowed in **new** CSS this phase: **400** and **600** only.

## Color

Inherit Phase 7 palettes verbatim. Do not add overlay-only tokens (`--led`, `--accent-dim`, `--radius`, `--shadow`, `--display`).

### Dark (60 / 30 / 10) — `:root` default

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#121417` (`--bg`) | Page canvas; hover/active button **text** (`color: var(--bg)`) |
| Secondary (30%) | `#1a1d21` (`--panel`) | `.tool-panel` surface |
| Accent (10%) | `#2dd4bf` (`--accent`) | Reserved list below |
| Destructive | `#f87171` (`--danger`) | Existing `.tool-error` only — this phase does not add a new error banner |
| Text | `#e8eaed` (`--text`) | FAQ summary + answer; panel body copy |
| Muted | `#9aa0a6` (`--muted`) | Footer only — do **not** mute FAQ answers |
| Border | `#2a2f36` (`--border`) | `.tool-panel` 1px border **and** `box-shadow` color |

### Light — `:root[data-theme="light"]` only

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f4f6f8` (`--bg`) | Page canvas; hover/active button **text** |
| Secondary (30%) | `#ffffff` (`--panel`) | `.tool-panel` surface |
| Accent (10%) | `#0f766e` (`--accent`) | Same reserved list as dark |
| Destructive | `#b91c1c` (`--danger`) | Existing `.tool-error` only |
| Text | `#1a1d21` (`--text`) | FAQ summary + answer |
| Muted | `#5c6570` (`--muted`) | Footer only |
| Border | `#d5dbe3` (`--border`) | `.tool-panel` 1px border **and** `box-shadow` color |

Accent reserved for:

- In-page text links (`a { color: var(--accent) }`) — unchanged
- `.nav-links a:hover` — unchanged
- `:focus-visible` 2px outline on `a` and `button` (existing HEAD rule) **and** `.faq summary:focus-visible` (same 2px / 2px offset)
- `.tool-panel button` idle **border + text** (existing)
- `.tool-panel button:hover:not(:disabled)` **fill** (`background: var(--accent)`) with `color: var(--bg)` (new this phase)
- `.tool-panel button:active:not(:disabled)` **darkened fill** (`color-mix(in srgb, var(--accent) 72%, #000000)`) (new this phase)
- `.tool-card:hover` text color (Phase 9 — do not restyle this phase)

Accent is **not** for: page canvas, panel idle fill, panel idle border, body grid, hamburger / ThemeToggle default icon color or hover fill, QR modules, diff hunks, danger errors, FAQ text, `::marker` color (marker uses `--text`).

Do not give idle `.tool-panel button` an accent fill. Idle is transparent fill + accent stroke + accent text. No `:active` scale. Do not add a second focus ring on `.tool-panel button` — keep the existing global `a:focus-visible, button:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px; }`.

Eyeball WCAG AA **4.5:1** in both themes on: idle button accent-on-panel, hover `--bg`-on-accent, active darkened-accent with `--bg` text, FAQ `--text` on the page canvas, panel `--text` on `--panel`. Disabled Copy is `opacity: 0.45` (WCAG 1.4.3 non-text/disabled exemption) — do not try to keep 4.5:1 on disabled. No contrast npm package.

## Interaction contract

| Moment | What the visitor sees |
|--------|------------------------|
| Tool panel at rest | `--panel` fill, 1px `--border`, `0 1px 2px var(--border)` shadow, `var(--sp-4)` padding, 8px radius. Copy is transparent with accent stroke + accent text. |
| Hover an enabled `.tool-panel button` | Fill becomes `--accent`; text becomes `--bg`; 120ms color transition. No scale. |
| Press (`:active`) an enabled `.tool-panel button` | Fill and border darken via `color-mix(in srgb, var(--accent) 72%, #000000)`; text stays `--bg`. No scale. |
| Keyboard focus a button | Existing 2px `--accent` outline, 2px offset. |
| Copy with empty output | Button `disabled`, opacity 0.45, `not-allowed` cursor; hover/active do not invert. |
| Copy with output | Click writes clipboard; label `Copied` for 1500ms, then `Copy`. |
| Hover hamburger or theme toggle | Unchanged Phase 8 / 7 icon chrome — **not** accent-filled. |
| FAQ first paint | `h2` FAQ; every `<details>` closed; UA triangle via `::marker`. |
| Open one FAQ | That item expands in place; others stay as they were (independent). |
| Keyboard focus a summary | 2px `--accent` outline, 2px offset. Enter/Space is native disclosure. |
| Light theme | Panel uses light `--panel` / `--border`; hover uses light `--accent` fill with light `--bg` text; FAQ `--text` on light canvas. |
| `prefers-reduced-motion: reduce` | Button color transition is `none`. |

No LED. No exclusive accordion. No JS for FAQ.
