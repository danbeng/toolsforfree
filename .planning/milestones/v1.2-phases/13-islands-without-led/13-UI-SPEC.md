## Markup (HEAD ToolShell + locale)

`src/components/ToolShell.tsx` — clone **HEAD** layout, then add required `locale` and `t(locale)` labels. Named export. Preact `class` (not `className`).

```tsx
import { useState } from 'preact/hooks';
import type { ComponentChildren } from 'preact';
import type { Locale } from '../i18n/locales';
import { t } from '../i18n/ui';

export function ToolShell(props: {
  error: string | null;
  output: string;
  locale: Locale;
  children: ComponentChildren;
}) {
  const [copied, setCopied] = useState(false);
  const copy = t(props.locale);

  async function onCopy() {
    if (!props.output) return;
    await navigator.clipboard.writeText(props.output);
    setCopied(true);
    window.setTimeout(() => setCopied(false), 1500);
  }

  return (
    <div class="tool-panel">
      {props.children}
      {props.error ? <p class="tool-error" role="alert">{props.error}</p> : null}
      <pre class="tool-output"><code>{props.output}</code></pre>
      <button type="button" onClick={onCopy} disabled={!props.output}>
        {copied ? copy.copied : copy.copy}
      </button>
    </div>
  );
}
```

Order is locked: **children → error → `<pre>` → Copy button**. Do not move Copy into a header bar.

Rules:

- `locale` is **required**. Drop optional `locale?` and `?? 'en'`.
- Import `Locale` from `../i18n/locales` (not from `ui.ts`).
- `disabled={!props.output}` — empty string disables Copy.
- Copied timeout stays **1500ms** (HEAD).
- No clipboard-failure UI (HEAD `onCopy` has no `try/catch` UI).
- Do not wrap children in `.tool-panel__body`.

## Interaction contract

| Click Copy with empty output | No-op (`onCopy` returns). Button stays disabled. |
| Parse / too-large error | `.tool-error` `role="alert"` in `--danger`. Islands pass empty `output` so Copy disables. |
