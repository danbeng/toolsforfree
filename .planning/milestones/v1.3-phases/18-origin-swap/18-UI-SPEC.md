# Phase 18 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

This phase is a **link and head-metadata contract**, not a visual change. It swaps the origin to `https://danbeng.github.io` and routes every internal `href` through a base-aware helper so links land under `/toolsforfree/`. Only `href` attribute values and `<head>` `link`/`meta` values change. It does **not** add CSS, copy strings, components, or Tailwind. It does **not** change markup structure or class names. It does **not** add a custom domain. It does **not** change `CONTACT_EMAIL` (`hello@example.com`, D-02).

Sources: `18-CONTEXT.md` (D-01..D-13, locked), approved `17-UI-SPEC.md` (tokens and exceptions inherited verbatim), `15-UI-SPEC.md` (404 LangSwitch override and noindex).

## Interaction contract

No visible chrome changes. Link targets change; link text, order, and styling do not.

### Internal links (ORIG-03, D-04, D-05, D-08)

- Every internal link lands on an existing page under `/toolsforfree/`. Covered surfaces: Header (logo + nav), Footer, ToolCard, RelatedTools, LangSwitch, EN/ZH home (category links + "View all tools"), EN/ZH blog index, 404 CTA, plus any other root-relative `href` in `src/` found by grep.
- Built HTML contains no `href="/` that does not start with `/toolsforfree/`, and no `/zh/toolsforfree`.
- ZH home category anchors resolve to `/toolsforfree/zh/tools/#category-...`.
- Asset URLs Astro already prefixes (`/toolsforfree/_astro/...`) are untouched.
- With base `/`, every href equals its logical path (helper is a no-op).

### LangSwitch (D-07)

- On a normal page, LangSwitch toggles between `/toolsforfree/...` and `/toolsforfree/zh/...` for the same logical page. Example: `/toolsforfree/tools/json-formatter/` ↔ `/toolsforfree/zh/tools/json-formatter/`.
- The current-locale item keeps its existing `aria-current` treatment. No new style.
- On 404, LangSwitch still points at the two home pages (Phase 15 `path="/"` override): `/toolsforfree/` and `/toolsforfree/zh/`. No `/zh/404/` link. Do not add `src/pages/zh/404.astro`.

### Head metadata (ORIG-01, ORIG-02, D-09..D-11)

- Canonical and the three alternates (`en`, `zh`, `x-default`) are absolute on `https://danbeng.github.io/toolsforfree/...`. No `example.com` anywhere in canonical, hreflang, sitemap, or robots.
- 404 keeps canonical at base + `/404/`, no alternates, `noindex` (Phase 15).
- `robots.txt` `Sitemap:` reads `https://danbeng.github.io/toolsforfree/sitemap-index.xml`.

### Out of scope (do not paint)

- No new CSS class, stylesheet block, component, icon, or copy string. No markup structure change.
- No custom domain, no `public/CNAME`, no `CONTACT_EMAIL` change, no `base` removal.
- Do not edit `ci.yml` or `deploy.yml`. Do not commit `src/lib/crontab.ts` or LED `ToolShell`.
