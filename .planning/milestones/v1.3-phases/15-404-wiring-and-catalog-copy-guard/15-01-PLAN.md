<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Requested URL → 404 document | Unknown paths, including `/zh/...`, render the root 404. The requested path must not become a canonical or a locale alternate. |
| Catalog tool → UI copy | `copy.tools[slug]` is an in-repo dictionary. A missing key is a content gap, not a place to throw or to inject new strings. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15-01 | Information Disclosure | BaseLayout hreflang and LangSwitch href | medium | mitigate | 404 sets `langSwitchPath` to `/` and `noindex`. Layout omits all three alternate links when `noindex` is set. Canonical uses the given `path` (`/404/`) and does not call `switchLocalePath`. Build grep must find no `zh/404` in `dist`. |
| T-15-02 | Tampering | BaseLayout `noindex` flag | low | accept | Flag is a compile-time Astro prop, default off, set only from `src/pages/404.astro`. No request parameter can turn it on. Other pages omit it. |
| T-15-03 | Denial of Service | ToolCard and RelatedTools missing-key lookup | medium | mitigate | `toolLabels` returns catalog `name` / `shortDescription` when the key is absent. Neither component throws. A present entry is not replaced. |
| T-15-04 | Information Disclosure | 404 robots meta | low | accept | Meta is `noindex` only. No `nofollow`, no visible badge, no new copy. |
</threat_model>
