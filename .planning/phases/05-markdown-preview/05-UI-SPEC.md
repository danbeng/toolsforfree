# Phase 5 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Spacing Scale

Declared values (must be multiples of 4). Map to existing rem at 16px root:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline code padding; task-checkbox-to-text gap; table cell tight inset |
| sm | 8px | Compact gaps (list-item margin, table cell padding, chrome inner gap) |
| md | 16px | Default: `.tool-panel__body` padding, pane grid gap, label-to-control gap, `.md-preview` padding, heading/blockquote/hr vertical rhythm |
| lg | 24px | Section break between island and page How-to (existing `h2` margin — do not change page layout); list `padding-left` inside `.md-preview` |
| xl | 32px | Not used inside the island |
| 2xl | 48px | Not used inside the island |
| 3xl | 64px | Not used inside the island |

Exceptions:

- Touch targets stay **44px** min-height (existing `textarea` / `button`). 44 is not on the 4/8/16 scale; do not shrink below 44px. Rendered GFM task-list checkboxes inside `.md-preview` are content, not chrome — they stay native size and `disabled`.
- Input border-radius stays **6px** (existing `.tool-panel textarea` and `.md-preview` pane). Panel radius stays **10px** (`--radius`). Do not retokenize radius to 8px.
- Source textarea `min-height` is **160px** (existing `10rem`). Preview pane `min-height` is **160px** and `max-height` is **384px** (24rem) with vertical scroll.

## Typography

Exactly four sizes, two weights. Island chrome labels match existing tools: uppercase tracked mono labels. Preview body uses `--sans`. Source, fences, inline code, and ToolShell copy payload use `--mono`. Do not use Syne inside the island or `.md-preview`.

| Role | Size | Weight | Line Height | Where |
|------|------|--------|-------------|-------|
| Label | 12px (0.75rem; existing labels are 0.72rem — use the existing `.tool-panel label` rule, do not add a new size) | 400 | 1.2 | Source label, Preview label, output bar |
| Body | 16px | 400 | 1.5 | `.md-preview` paragraphs, list items, table cells, blockquote text. Page intro stays existing `body` 16px / 1.55 — island preview uses 1.5 |
| Code | 14px (existing `.tool-output` 0.88rem) | 400 | 1.5 | Source textarea, fenced `pre code`, inline `code`, ToolShell copy payload |
| Heading | 20px (existing `h2` 1.25rem) | 600 | 1.2 | `.md-preview h1` only. `.md-preview h2`–`h6` stay Body size (16px) at weight 600 |

Weights in this island: **400** and **600** only. Do not use Syne 750/800 inside the island. Do not introduce 500 or 700. Table headers (`th`) use Body 16px at 600.

| Element | Copy |
|---------|------|
| Primary CTA | EN `Copy` / ZH uses existing ToolShell control (do not add a second button). Payload is the **sanitized HTML** string (MD-04). |
| Empty state heading | none — MD-05 forbids placeholder copy in the preview. The preview pane is blank. Do not render an empty heading inside or beside `.md-preview`. |
| Empty state body | none — idle uses a blank `.md-preview` plus existing ToolShell idle (Copy disabled, `<pre class="tool-output">` empty). Privacy copy lives in page FAQ / `.local-note`, not in the preview. |
| Error state | EN `Input too large to process in the browser.` / ZH `输入过长，无法在浏览器中处理。` Shown via ToolShell `role="alert"`. Preview cleared. Copy disabled. |

## Layout

**Primary visual anchor:** After the source textarea has any character, the `.md-preview` pane is the island's focal point (live GFM HTML). While source is empty, the source textarea is the anchor. ToolShell `<pre class="tool-output">` is the copyable sanitized HTML, not the reading surface.

Vertical order **inside** `ToolShell` children, then the existing error + output wrap:

1. **Split panes** — `div.tool-grid.split` with two children, source first:
   - Left / top: `<label>` + `<textarea>` using `markdown` copy. `spellcheck={false}`. Existing textarea styles.
   - Right / bottom: `<label>` using `preview` copy + `div.md-preview` (the visual HTML surface).
2. At `min-width: 720px` the grid is `1fr 1fr` (existing `.tool-grid.split`). Below 720px the panes stack: **source then preview**. No extra layout library. No synchronized scroll.
3. Existing `ToolShell` error (`role="alert"`) + `<pre class="tool-output">` copy payload.

Do not put the visual preview only inside ToolShell `<pre>`. The `<pre>` is the **copyable sanitized HTML** (MD-04). The reading surface is `.md-preview`.

`.md-preview` pane chrome (additive CSS only):

- `min-height: 160px; max-height: 384px; overflow-y: auto; overflow-x: auto;`
- `background: var(--bg); border: 1px solid var(--border); border-radius: 6px; padding: 16px;`
- `font-family: var(--sans); font-size: 16px; line-height: 1.5; color: var(--text);`
- Idle and too-large: the element remains in the layout and is **empty** (no children, no placeholder node, no dashed empty card).

GFM inside `.md-preview` (no new color tokens):

| GFM node | Treatment |
|----------|-----------|
| `h1` | Heading role 20px / 600 / 1.2, `--sans`, `--text`. Margin-top 16px except `:first-child`. |
| `h2`–`h6` | Body size 16px / 600 / 1.2, `--sans`, `--text`. Same 16px top margin except first child. |
| `p`, `li` | Body 16px / 400 / 1.5 |
| `ul` / `ol` | `padding-left: 24px`; `li` margin 8px |
| Task list | Native checkbox `disabled` (preview is not an editor). 4px gap to label text. |
| Inline `code` | Code role, `--mono`, `--bg-elev` fill, 4px padding, 6px radius |
| Fenced `pre` | Code role, `--mono`, `--bg-elev` fill, 16px padding, `overflow-x: auto; white-space: pre;`. Marked may emit `language-*` class — **no highlight.js / Prism**; class has no token colors this phase |
| Table | `width: 100%; border-collapse: collapse;` `th`/`td` padding 8px, `1px solid var(--border)`. `th` weight 600 |
| Blockquote | `border-left: 4px solid var(--border); padding-left: 16px; color: var(--muted);` |
| `hr` | `1px solid var(--border); margin: 16px 0;` |
| `a` | Existing global accent link color (reserved) |
| `del` | `text-decoration: line-through; color: var(--text);` |
| `img` | **Not rendered.** Strip all `img` (safer default — no data-URI, no http/https). No broken-image icon |

## Interaction

- Live compute: `onInput` on the source textarea recomputes via `useMemo` (same as `SqlFormatter`). No Generate button. No debounce required in the UI contract (engine may hitch at cap; no worker this phase).
- `isTooLarge` runs on the Markdown **source** against `INPUT_MAX_CHARS` (100_000) **before** parse. If over cap: show the error-state string, clear `.md-preview`, clear copy payload, do not run Marked or DOMPurify.
- Empty source (`''`): idle — skip parse, blank `.md-preview`, empty copy payload, Copy disabled. Whitespace-only source may still parse; if sanitizer returns `''`, treat as idle Copy-disabled with a blank preview (still no placeholder).
- Engine: Marked GFM parse, then DOMPurify. Never Marked `sanitize`. Island may use `dangerouslySetInnerHTML` **only** of the already-sanitized HTML string. Forbidden: `innerHTML` / `dangerouslySetInnerHTML` of unsanitized Marked output; concatenating source into HTML strings.
- ToolShell `output` (copy payload) is the sanitized HTML string (MD-04). Empty when idle or too-large. Copy remains the existing ToolShell button; disabled when `output` is empty.
- XSS payloads in source must not execute after sanitize. Remote `![alt](https://…)` must not cause a network fetch — all `img` stripped, so no request and no broken-image UI.
- Image-only (or otherwise fully stripped) source: `.md-preview` stays blank, Copy disabled if payload is `''`. Do not show “images blocked” inside the pane (FAQ covers it).
- Links that survive sanitize use default in-page navigation. Do not force `target="_blank"`.
- `spellcheck={false}` on the source textarea.
- No syntax highlighter this phase. Fences render as uncolored mono.
- No `aria-live` on `.md-preview` (would re-announce the whole document every keystroke). Associate the Preview label with the pane (`aria-labelledby` or wrapping label). Preview is not a textbox.

## UI Considerations

Applicable state considerations resolved: 8 covered, 0 backstop, 0 unresolved. Loading dismissed (local `useMemo`, no network).

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | form (source), static-content (preview) | ✅ covered | Empty source → blank `.md-preview` (no heading, no body, no placeholder); ToolShell Copy disabled; see Copywriting empty rows |
| loading | form, interactive-control | ✅ covered | Dismissed: compute is synchronous in the island; no spinner, skeleton, or disabled overlay |
| error | form, interactive-control | ✅ covered | Too-large string in Copywriting; `role="alert"` via ToolShell; preview and copy payload cleared; Marked/DOMPurify not called |
| populated | static-content (preview) | ✅ covered | Typical volume is a short GFM doc: headings, lists, links, fences, tables, strikethrough, task lists inside `.md-preview` at Body/Code/Heading roles, 384px max-height scroll |
| partial | form, static-content | ✅ covered | Source filled but sanitizer strips everything (e.g. only remote images) → blank preview, Copy disabled if payload `''`; source textarea still shows the Markdown |
| overflow | static-content, list-collection (tables/lists inside preview) | ✅ covered | `.md-preview` `max-height: 384px; overflow-y: auto; overflow-x: auto`; fences `overflow-x: auto`; tables scroll with the pane rather than stretching the page; textareas `resize: vertical` with min-height 160px |
| zero-one-many | list-collection (GFM lists/tables) | ✅ covered | Zero blocks in idle/error: preview omitted children. One heading/list item/table row: same node styles, no plural special case. Many blocks: same styles, scroll the pane not the page |
| long-text | form, static-content | ✅ covered | Source wraps inside the textarea. Preview body `overflow-wrap: anywhere`. Fences keep `white-space: pre` and scroll horizontally inside the pane. User text is never truncated with ellipsis (a truncated preview is a wrong preview) |
