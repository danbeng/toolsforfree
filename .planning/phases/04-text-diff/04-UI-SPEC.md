## Spacing Scale

Declared values (must be multiples of 4). Map to existing rem at 16px root:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Prefix-to-text gap on a diff line; checkbox-to-label gap |
| sm | 8px | Compact gaps (stats row wrap gap, chrome inner gap) |
| md | 16px | Default: `.tool-panel__body` padding, pane grid gap, label-to-control gap, stats-to-panes gap |
| lg | 24px | Section break between island and page How-to (existing `h2` margin — do not change page layout) |
| xl | 32px | Not used inside the island |
| 2xl | 48px | Not used inside the island |
| 3xl | 64px | Not used inside the island |

Exceptions:

- Touch targets stay **44px** min-height (existing `textarea` / `button` / `input` / checkbox hit area). 44 is not on the 4/8/16 scale; do not shrink below 44px.
- Input border-radius stays **6px** (existing `.tool-panel textarea`). Panel radius stays **10px** (`--radius`). Do not retokenize radius to 8px.
- Each pane textarea `min-height` is **160px** (existing `10rem`). Diff line list `max-height` is **384px** (24rem) with vertical scroll.

Weights in this island: **400** and **600** only. Do not use Syne 750/800 inside the island. Do not introduce 500.

Accent reserved for:

## Copywriting Contract

Island keys live under `ui.en.tools['text-diff']` and `ui.zh.tools['text-diff']`. English lib errors map in `ZH_ERRORS` in the same slice (CAT-06). ToolShell Copy control keeps the existing `Copy` / `Copied` chrome — do not invent a second copy widget.

| Element | Copy |
|---------|------|
| Primary CTA | EN `Copy` / ZH uses existing ToolShell control (do not add a second button). Payload is the unified text summary defined under Interaction. |
| Empty state heading | EN `Paste original and changed text` / ZH `粘贴原文和改后文本` |
| Empty state body | EN `Diff runs in your browser. Nothing is uploaded.` / ZH `比较在浏览器本地完成，不会上传内容。` Shown only when **both** panes are empty (idle). Not shown for identical non-empty texts. |
| No differences heading | EN `No differences` / ZH `无差异` |
| No differences body | EN `The two texts match.` / ZH `两段文本相同。` |
| Error state (original pane) | EN `Original text is too large to process in the browser.` / ZH `原文过长，无法在浏览器中处理。` |
| Error state (changed pane) | EN `Changed text is too large to process in the browser.` / ZH `改后文本过长，无法在浏览器中处理。` |
| Error state (both panes) | EN `Original and changed text are too large to process in the browser.` / ZH `原文和改后文本都过长，无法在浏览器中处理。` |
| Destructive confirmation | none — this phase has no destructive action |

Locked control labels:

| Key | EN | ZH |
|-----|----|----|
| `name` | Text Diff | 文本对比 |
| `shortDescription` | Compare two texts line by line in your browser. | 在浏览器里逐行对比两段文本。 |
| `original` | Original | 原文 |
| `changed` | Changed | 改后 |
| `added` | Added | 新增 |
| `removed` | Removed | 删除 |
| `ignoreWhitespace` | Ignore leading/trailing whitespace | 忽略行首行尾空白 |
| `noDifferences` | No differences | 无差异 |

Stats display: `{n} {added}` and `{n} {removed}` with the numeric `n` at Stat role (20px/600) and the word at Label role. Example EN: `2 Added` / `1 Removed`. Example ZH: `2 新增` / `1 删除`. Always integer, never "2 lines added".

## Layout

Vertical order **inside** `ToolShell` children, then the existing error + output wrap:

1. **Stats row** — two `.tool-card` tiles (Added, Removed) in a 2-column grid. Hidden when both panes are empty (idle). Visible whenever at least one pane has characters, including identical texts (`0` / `0`).
2. **Whitespace toggle** — one native checkbox, default **unchecked**. Label is `ignoreWhitespace`. Same markup pattern as `PasswordGenerator` (checkbox inside `<label>`).
3. **Two panes** — `div.tool-grid.split`: Original textarea, Changed textarea. At `min-width: 720px` side by side (`1fr 1fr`); below 720px stacked Original then Changed. No extra layout library. No synchronized scroll (deferred).
4. **Visual diff list** — `ol.diff-lines` (or `div.diff-lines` with one child per line). **One node per line** with `diff-line diff-line--add|del|eq`. Never a single highlighted `<pre>` as the only view (DIFF-02). Never `innerHTML` / string-concatenated markup.
5. Existing `ToolShell` error (`role="alert"`) + `<pre class="tool-output">` copy payload.

Do not put the visual list only inside ToolShell `<pre>`. The `<pre>` is the **copyable unified summary**, not the highlighted view.

## Interaction

- Live compute: `onInput` on either pane or toggling the checkbox recomputes via `useMemo` (same as `SqlFormatter` dialect). No Generate button. No debounce required in the UI contract (engine may hitch at cap; no worker this phase).
- Checkbox default **off** = exact diff. On = trim leading/trailing whitespace **per line**, not collapse internal spaces, not drop blank lines (DIFF-03).
- `isTooLarge` runs **independently per pane** against `INPUT_MAX_CHARS` (100_000). If either pane is over cap: show the matching error, clear visual list, clear copy payload, do not call the diff engine.
- Both panes empty or whitespace-only: idle `{ ok: false, error: '' }` — empty-state copy in the visual area, Copy disabled, stats hidden.
- One pane empty and the other not: entire non-empty side is adds (changed only) or deletes (original only).
- Identical non-empty texts: stats `0` / `0`, visual area shows No differences heading + body, copy payload is the No differences heading text so Copy is enabled.
- ToolShell `output` (copy payload) format — labeled summary, **not** `createTwoFilesPatch` (unified patch download is DIFF-08 / deferred):

```
Added: 2
Removed: 1

- deleted line
+ added line
  unchanged line
```

First two lines use EN labels `Added` / `Removed` when `locale === 'en'`, ZH `新增` / `删除` when `locale === 'zh'`. Body lines use `- ` / `+ ` / two spaces. Empty copy payload when idle or too-large.

- Highlighting: set `class` on each line node; set text with Preact children. Forbidden: `innerHTML`, `dangerouslySetInnerHTML`, concatenating user text into HTML strings.
- `spellcheck={false}` on both textareas.
- Copy remains the existing ToolShell button; disabled when `output` is empty.

## UI Considerations

Applicable state considerations resolved: 8 covered, 0 backstop, 0 unresolved. Loading dismissed (local `useMemo`, no network).

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | form (two panes), list-collection (diff lines) | ✅ covered | Both panes empty → idle visual uses Copywriting empty heading + body; stats hidden; Copy disabled; no "No differences" |
| loading | form, interactive-control | ✅ covered | Dismissed: compute is synchronous in the island; no spinner, skeleton, or disabled overlay |
| error | form, interactive-control | ✅ covered | Per-pane too-large strings in Copywriting; `role="alert"` via ToolShell; visual list and copy payload cleared; diff engine not called |
| populated | list-collection (diff lines) | ✅ covered | Typical volume is tens of lines: each line is one node with add/delete/eq class, `+`/`-`/spaces prefix, 14px mono, 384px max-height scroll |
| partial | form | ✅ covered | One pane empty + one filled → all-add or all-delete rows; stats reflect that; empty pane still shows its textarea |
| overflow | list-collection, static-content | ✅ covered | Diff list `max-height: 384px; overflow-y: auto; overflow-x: auto`; line text `white-space: pre-wrap; overflow-wrap: anywhere`; textareas `resize: vertical` with existing min-height 160px |
| zero-one-many | list-collection | ✅ covered | Zero lines in idle/error: list omitted. One line: single row, no plural special case. Many lines: same row component, scroll the list not the page |
| long-text | form, static-content | ✅ covered | Pane values wrap inside the textarea. Diff row text wraps (`pre-wrap`) rather than forcing a page-wide horizontal scroll. User text is never truncated with ellipsis (a truncated diff is a wrong diff) |
