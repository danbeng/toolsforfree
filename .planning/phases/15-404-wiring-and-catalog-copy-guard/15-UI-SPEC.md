# Phase 15 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

This phase is a **bug-fix wiring contract**, not a visual redesign. A visitor who hits the existing root 404 must not be sent to a missing Chinese 404, and a catalog card must still paint when a tool's UI copy key is absent. Same markup, same classes, same strings. Do **not** add `src/pages/zh/404.astro`. Do **not** special-case `/404/` inside `src/i18n/path.ts`. Do **not** change `SITE_ORIGIN`. Do **not** add Tailwind, a component library, new CSS classes, or new copy strings. Do **not** add npm packages.

Sources: `15-CONTEXT.md` (D-01..D-07, locked), `ROADMAP.md` Phase 15, `REQUIREMENTS.md` GUARD-01..05, approved `12-UI-SPEC.md` (chrome tokens — inherit, do not restyle), `src/styles/global.css`, `src/pages/404.astro`, `src/components/LangSwitch.astro`, `src/layouts/BaseLayout.astro`, `src/components/Header.astro`, `src/components/ToolCard.astro`, `src/components/RelatedTools.astro`, `src/i18n/ui.ts`, `src/data/tools.ts`.

Discretion locked here (CONTEXT.md left these open):

- Header threads an optional `langSwitchPath` prop into LangSwitch. Other pages omit it. Do not render a second switch on the 404 page.
- 404 canonical stays the layout `path` (`/404/`) resolved against `SITE_ORIGIN`. It is not the requested URL and it is not `/zh/404/`. Alternates are omitted on that document only.

## Interaction contract

Same visible chrome. Only the hrefs, the head links, and the fallback text change.

### LangSwitch (GUARD-01)

- Add an optional path override prop. Default is `Astro.url.pathname` so every page that does not pass it keeps today's equivalent-path links.
- Header accepts the same optional prop and passes it through. Pages other than 404 omit it.
- `src/pages/404.astro` sets the override to `/`. English link is home (`/`). Chinese link is home in the other locale (`/zh/`). Neither href is `/404/` or `/zh/404/`.
- Do not special-case `/404/` in `switchLocalePath`. The override is how the 404 page avoids feeding `/404/` into the zh branch.
- Markup stays `<nav class="lang-switch">` with two `<a>` elements, `hreflang`, `lang`, and `aria-current="page"` on the current locale. Current locale remains a link, not a `<span>`.
- Do not put LangSwitch inside `#navMenu`. Do not add a second switch in the 404 main.

### Canonical, hreflang, noindex (GUARD-02, GUARD-03)

- `BaseLayout` gains an optional flag, default off. Only `src/pages/404.astro` sets it.
- When the flag is off, keep today's three `<link rel="alternate">` tags (en, zh-Hans, x-default) and do not emit `noindex`.
- When the flag is on, omit all three alternate links. Do not point any of them at `/zh/404/` or at home as a substitute alternate.
- When the flag is on, emit exactly `<meta name="robots" content="noindex">`. Do not add `nofollow`. Do not add a visible badge.
- Canonical on the 404 document is `new URL('/404/', SITE_ORIGIN)` via the existing layout `path="/404/"` plus `switchLocalePath` only if that call cannot produce `/zh/404/`. Preferred: when the flag is on, set canonical from `path` as given (`/404/`) and do not run the zh branch of `switchLocalePath` for this document. Requested URL is not the canonical. `/zh/404/` is not the canonical.
- `SITE_ORIGIN` stays the current constant. Do not rewrite it.

### Catalog fallback (GUARD-04, GUARD-05)

- `ToolCard` and `RelatedTools` must not throw when `copy.tools[slug]` is missing. Do not add `throw new Error` as the fix.
- If the UI-copy entry is present, use it. Do not replace a present entry with catalog fields.
- If the entry is missing, `ToolCard` title is `tool.name` and the paragraph is `tool.shortDescription`. Same `<a class="tool-card">` markup. No extra class, no "untranslated" label.
- If the entry is missing, `RelatedTools` link text is `tool.name`. Same `<ul class="related"><li><a>` markup. Do not render `shortDescription` in the related list (that list is name-only today).
- `ToolCard` `locale` stays optional, default `en`. Do not widen the prop to required. Do not edit every call site.
- `RelatedTools` `locale` stays required, as today.

### Out of scope (do not paint)

- No `src/pages/zh/404.astro`. Unknown paths, including `/zh/...`, stay on the root 404 document.
- No new CSS class, no new stylesheet block, no illustration, no skeleton.
- No compile-time `keyof` that fails the build when a UI key is missing. This phase must not throw at render time.
- Do not commit `src/lib/crontab.ts` or LED `ToolShell`. Do not change `SITE_ORIGIN`.
