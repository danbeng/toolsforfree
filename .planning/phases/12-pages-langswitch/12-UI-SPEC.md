# Phase 12 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

This phase lands **header language switching** and the **ZH page tree** on HEAD chrome. Visitors browse EN (unprefixed) or ZH (`/zh/`) and jump to the equivalent URL without a new visual system. Work from **HEAD** `Header.astro`, `BaseLayout.astro`, `FaqList.astro`, and `src/styles/global.css`. Mount the already-written `LangSwitch.astro`. Do **not** pop `stash@{0}` or `stash@{1}`. Do **not** copy overlay LED `tool-panel__chrome`, IBM Plex / Syne, or stash Header/CSS. No Tailwind, no shadcn, no icon pack, no new npm packages.

Sources: `12-CONTEXT.md` (locked), `10-UI-SPEC.md` (color / type / FAQ chrome — inherit), `REQUIREMENTS.md` PAGE-01–05, `src/styles/global.css` tokens. ## Spacing Scale

Inherit Phase 9 `--sp-1`…`--sp-12` on `:root`. Do **not** redefine them. Do **not** duplicate them under `:root[data-theme="light"]`.

Declared values (multiples of 4). This phase **consumes only `--sp-2`** for LangSwitch:

| Token | Value | Usage this phase |
|-------|-------|------------------|
| xs (`--sp-1`) | 4px | Existing only — do not retokenize |
| sm (`--sp-2`) | 8px | `.lang-switch` `gap` |
| md (`--sp-4`) | 16px | Existing wrap / overlay / panel — do not retokenize |
| lg (`--sp-5`) | 24px | Existing `.nav` gap — do not retokenize |
| xl (`--sp-6`) | 32px | Existing `main section` margin — do not retokenize |
| 2xl (`--sp-7`) | 48px | Existing only — do not retokenize |
| 3xl (`--sp-8`) | 64px | Existing only — do not retokenize |

`--sp-3: 12px` exists on `:root`. Do **not** use it in new LangSwitch CSS.

Do **not** retokenize: `.nav` `gap: var(--sp-5)`, `.nav-links` `gap: 1rem`, hamburger overlay `gap: 16px` / `padding: 16px` / `padding: 8px 0`, `#navToggle` / `#themeToggle` 44px boxes, footer `3rem` / `1.5rem` / `2.5rem`, `--content: 52rem`, catalog grid, tool-panel.

- Hamburger and theme toggle hit targets stay **44×44px**. Do not restyle them as LangSwitch text, and do not restyle LangSwitch as 44px icon buttons.

## Typography

Exactly three sizes, two weights for **new** CSS this phase. Inherit Phase 7 / 10 / HEAD. Do not restyle page `h1` / `h2`, FAQ, or tool chrome.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 14px | 400 | 1.2 |
| Body | 16px | 400 | 1.5 |
| Heading | 20px | 600 | 1.2 |

Where they apply this phase:

- **Body 16px / 400 / 1.5** — `.lang-switch a` idle. Nav Tools/Blog/About stay HEAD (no new size). 404 body / blog empty body inherit page body.
- **Heading 20px / 600 / 1.2** — existing page `h2` including FaqList’s English `FAQ`. Inherit only. Do **not** restyle `h2` this phase.
- **Label 14px / 400 / 1.2** — unused this phase. Do not add a “Language” visible caption next to the links (`aria-label` on the `<nav>` is enough).

`.lang-switch a[aria-current="page"]` is **16px / 600 / 1.5** (body size + heading weight). That is the current-locale indicator — not a color change, not an underline, not a pill.

Weights allowed in **new** CSS this phase: **400** and **600** only. Do not add 650, 700, or 500. Leave existing logo `650` untouched.

### `src/components/Header.astro`

Edit HEAD only. Mount order: logo → hamburger (`NavMenu`) → Tools/Blog/About (`.nav-links#navMenu`) → `LangSwitch` → `ThemeToggle`.

```astro
---
import { SITE_NAME } from '../data/site';
import ThemeToggle from './ThemeToggle.astro';
import NavMenu from './NavMenu.astro';
import LangSwitch from './LangSwitch.astro';
import type { Locale } from '../i18n/locales';
import { localizedPath } from '../i18n/path';
import { t } from '../i18n/ui';

interface Props {
  locale: Locale;
}

const { locale } = Astro.props;
const copy = t(locale);
---
<header class="site">
  <nav class="wrap nav">
    <a class="logo" href={localizedPath(locale, '/')}>{SITE_NAME}</a>
    <NavMenu locale={locale} />
    <div class="nav-links" id="navMenu">
      <a href={localizedPath(locale, '/tools/')}>{copy.navTools}</a>
      <a href={localizedPath(locale, '/blog/')}>{copy.navBlog}</a>
      <a href={localizedPath(locale, '/about/')}>{copy.navAbout}</a>
    </div>
    <LangSwitch locale={locale} />
    <ThemeToggle />
  </nav>
</header>
```

Rules:

- `locale` is **required**. Drop `locale?:` and `?? 'en'`.
- Logo `href` is always `localizedPath(locale, '/')` (EN → `/`, ZH → `/zh/`). Do not special-case a hardcoded `'/'` on EN.
- Do **not** put `<LangSwitch>` inside `#navMenu`.
- Do not pop `stash@{0}` Header.

## Interaction contract

| Moment | What the visitor sees |
|--------|------------------------|
| Header at rest (desktop) | Logo left; Tools / Blog / About; then `English` `中文` with 8px gap; then 44px ThemeToggle. Current locale is weight 600, same `--text` as idle. |
| Hover a non-current LangSwitch link | Text color `--accent`. No fill, no underline, no scale. |
| Hover the current LangSwitch link | Same accent text hover. Link stays a link. |
| Keyboard focus a LangSwitch link | Existing 2px `--accent` outline, 2px offset. |
| Click the other locale | Full navigation to `switchLocalePath` equivalent (trailing slash). No client-side swap, no flash of a dropdown. |
| Click the current locale | Navigate to the same-locale equivalent URL (still a real `href`). |
| Header at rest (≤640px) | Logo; 44px hamburger; LangSwitch + ThemeToggle clustered on the right. Tools/Blog/About stay in the overlay, not beside LangSwitch. |
| Hamburger closed | LangSwitch remains visible in the bar. Overlay `.nav-links` is `visibility: hidden` + `inert` as Phase 8. |
| ZH page | `<html lang="zh-Hans">`; logo goes to `/zh/`; nav labels 工具 / 博客 / 关于; LangSwitch `aria-label` is `语言`; `中文` is `aria-current="page"`. |
| EN page | `<html lang="en">`; logo `/`; nav Tools / Blog / About; `aria-label` `Language`; `English` is current. |
| 404 under `/zh/…` | ZH 404 copy + CTA to `/zh/tools/`. Header locale is `zh`. |
| 404 under any other path | EN 404 copy + CTA to `/tools/`. |
| Light theme | LangSwitch `--text` / hover `--accent` follow light tokens. No extra LangSwitch rule. |
| FaqList on a ZH tool page | English `h2` `FAQ` plus existing details/summary rows. No second heading from `copy.faq`. |

No dropdown. No flags. No globe. No JS on LangSwitch. No LED. No stash pop.
