## Spacing Scale

Declared values (multiples of 4). Define all twelve on `:root` as `--sp-1`…`--sp-12` (LAY-02). Do **not** duplicate them under `:root[data-theme="light"]`.

| Token | Value | Usage this phase |
|-------|-------|------------------|
| `--sp-1` | 4px | Defined; unused on touched selectors |
| `--sp-2` | 8px | `.tool-card p` top margin (title → description). Overlay link `padding: 8px 0` stays a literal — not a touched selector |
| `--sp-3` | 12px | Defined; unused on touched selectors |
| `--sp-4` | 16px | `.card-grid` gap (home + catalog); `.tool-card` padding; `.wrap` horizontal padding (`padding: 0 var(--sp-4)`); `h2:has(+ .card-grid)` margin-bottom |
| `--sp-5` | 24px | `.nav` `gap` (was `1.25rem`) |
| `--sp-6` | 32px | `main section` margin-top (tools-index category blocks) |
| `--sp-7` | 48px | Defined; unused on touched selectors (body grid period stays 47px/48px geometry, not this token) |
| `--sp-8` | 64px | Defined; unused on touched selectors |
| `--sp-9` | 80px | Defined; unused on touched selectors |
| `--sp-10` | 96px | Defined; unused on touched selectors |
| `--sp-11` | 120px | Defined; unused on touched selectors |
| `--sp-12` | 144px | Defined; unused on touched selectors |

Touched selectors only (LAY-03): `.card-grid` gap, `.tool-card` padding, `.wrap` horizontal padding, `.nav` gap. Convert `1rem` → `--sp-4` and `1.25rem` → `--sp-5` in those selectors.

Do **not** retokenize: `.tool-panel`, `.diff-lines`, `.md-preview`, `.tool-grid`, footer `3rem` / `1.5rem` / `2.5rem`, `#navToggle` / `#themeToggle` 44px boxes, hamburger overlay `gap: 16px` / `padding: 16px` / `padding: 8px 0`.

Exceptions:

- Hamburger and theme toggle hit targets stay **44×44px**. 44 is the WCAG 2.2 target-size floor; do not shrink to `--sp-6` (32px) or `--sp-7` (48px).
- Body grid geometry stays **47px / 48px**. Do not replace with `--sp-7`.
- `.nav` `min-height: 3.25rem` (52px) stays as HEAD. Do not retokenize it.
- `.tool-grid` `gap: 1rem` stays a literal. Catalog uses `.card-grid` only.
- `--content: 52rem` stays. Do not widen the canvas to force 3 columns; 3 columns fit inside the current wrap.
- No 4-col at 1440px (deferred v2).

## Typography

Exactly four sizes, two weights. This phase does not restyle page type; it inherits Phase 7 / HEAD. HEAD `.nav a.logo` is `font-weight: 650` — **leave it**; do not “normalize” to 600.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 14px | 400 | 1.2 |
| Body | 16px | 400 | 1.5 |
| Code | 14px | 400 | 1.5 |
| Heading | 20px | 600 | 1.2 |

Where they apply this phase:

- **Body 16px / 400 / 1.5** — `.tool-card p` (shortDescription). Page body copy unchanged.
- **Label 14px / 400 / 1.2** — unused this phase. Do not add overlay eyebrows or category captions on cards.
- **Code 14px / 400 / 1.5** — existing tool controls; inherit only.
- **Heading 20px / 600 / 1.2** — existing `.md-preview h1` and page headings elsewhere; inherit only. Do **not** restyle home `h1` / `h2` or tools-index `h1` / `h2` font-size this phase.

`.tool-card strong` is **16px / 600 / 1.2** (body size + heading weight). Browser default `strong` is 700 — set `font-weight: 600` so this phase does not introduce a third weight. Do not use 20px on card titles (too large in a 3-col track).

Weights allowed in **new** CSS this phase: **400** and **600** only.

## Catalog grid

New rules in `global.css`. Do not reuse `.tool-grid` for catalog.

```css
.card-grid {
  display: grid;
  grid-template-columns: minmax(0, 1fr);
  gap: var(--sp-4);
}
@media (min-width: 720px) {
  .card-grid { grid-template-columns: repeat(2, minmax(0, 1fr)); }
}
@media (min-width: 1080px) {
  .card-grid { grid-template-columns: repeat(3, minmax(0, 1fr)); }
}
h2:has(+ .card-grid) {
  margin-bottom: var(--sp-4);
}
main section {
  margin-top: var(--sp-6);
}
main section > h2 {
  margin-top: 0;
}
```

Rules:

- Default 1 column. `min-width: 720px` → 2 columns (same breakpoint as existing `.tool-grid.split`). `min-width: 1080px` → 3 columns. Use `min-width` (not `max-width`) to match the 720px convention.
- No 4th column. No `auto-fit` / `auto-fill` that would create extra columns inside `--content`.
- `align-items` stays default stretch so cards in a row share height.
- A one-item grid occupies the first track only.

## Interaction contract

| Moment | What the visitor sees |
|--------|------------------------|
| Home, viewport &lt; 720px | Featured cards in one column, `--sp-4` gap, panel fill, 1px border. |
| Home, 720px–1079px | Featured cards in two columns. Existing tool-island `.tool-grid.split` still two columns at ≥720px. |
| Home / `/tools/`, ≥1080px | Cards in three columns inside `--content` (52rem). No overlap, no horizontal page scroll from the grid. |
| `/tools/` Auth (one tool) | One card in the first column; empty tracks stay empty. |
| Hover a card | Title + description turn `--accent`. Border and fill stay idle. |
| Keyboard focus a card | Existing 2px `--accent` outline, 2px offset. |
| Click a card | Navigate to `/tools/{slug}/`. No confirm. |
| Light theme | Cards use light `--panel` / `--border` / `--text`; hover uses light `--accent`. |
| Tool page split panes | `.tool-grid` unchanged (still 1-col / 2-col at 720px). Not 3-col. |

No spacing animation. No masonry. No equalizer JS.
