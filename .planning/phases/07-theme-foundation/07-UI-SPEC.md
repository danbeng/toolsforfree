## Spacing Scale

Declared values (multiples of 4). This phase does **not** introduce `--sp-*` tokens (Phase 9). Use these values only on the new toggle; do not migrate existing header/footer/tool-panel spacing.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Diff line `padding-left` already 4px — do not change. Not used on the toggle. |
| sm | 8px | Unused on the toggle (icon is optically centered in the hit target). |
| md | 16px | Existing `.nav-links` gap (`1rem`) and `.wrap` horizontal padding — keep. Space between About and the toggle is this gap. |
| lg | 24px | Unused this phase. |
| xl | 32px | Unused this phase. |
| 2xl | 48px | Body grid **repeat period** (47px transparent + 1px `--grid-line`). Not a padding token. |
| 3xl | 64px | Unused this phase. |

Exceptions:

- Theme toggle hit target is **44×44px** (`width` + `height` + `min-width` + `min-height` all 44px). 44 is the WCAG 2.2 target-size floor; do not shrink to 32/40.
- Grid geometry is **47px / 48px** (`transparent` through 47px, `--grid-line` 47px–48px). 47 is not on the 4px scale; do not “fix” it to 44 or 48px of solid line.
- Existing `.nav` `min-height: 3.25rem` (52px) and `gap: 1.25rem` stay as HEAD. Do not retokenize them.
- `.tool-panel` radius 8px and `.md-preview` / `.qr-preview` radius 6px stay as HEAD.

## Color

Two palettes. Dark hex on `:root` are HEAD verbatim. Light hex live **only** under `:root[data-theme="light"]`. If ThemeInit never runs, the site must still look like today’s dark page.

### Dark (60 / 30 / 10) — `:root` default

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#121417` (`--bg`) | Page canvas, `html`/`body` background-color, textarea/input fill, `.md-preview` / `.qr-preview` fill |
| Secondary (30%) | `#1a1d21` (`--panel`) | `.tool-panel` surface, `var(--bg-elev, var(--panel))` code chips |
| Accent (10%) | `#2dd4bf` (`--accent`) | Reserved list below |
| Destructive | `#f87171` (`--danger`) | `.tool-error` only — this phase does not add a theme-error banner |
| Text | `#e8eaed` (`--text`) | Body copy, logo, nav links, toggle icon `currentColor` |
| Muted | `#9aa0a6` (`--muted`) | Footer, `.diff-line--eq` |
| Border | `#2a2f36` (`--border`) | Header/footer rules, panels, inputs |
| Grid line | `rgba(42, 47, 54, 0.45)` (`--grid-line`) | 1px vertical body stripe |
| Diff add | fg `#3dd68c` / bg `#13291f` | `.diff-line--add` color, background, border-left |
| Diff del | fg `#f07178` | `.diff-line--del` color and border-left; no fill (HEAD) |

### Light — `:root[data-theme="light"]` only

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f4f6f8` (`--bg`) | Page canvas |
| Secondary (30%) | `#ffffff` (`--panel`) | Tool panels / elevated chips |
| Accent (10%) | `#0f766e` (`--accent`) | Same reserved list as dark |
| Destructive | `#b91c1c` (`--danger`) | `.tool-error` only. Re-tint vs research `#dc2626` (4.40:1 on `#f4f6f8`); `#b91c1c` is ≥4.5:1 |
| Text | `#1a1d21` (`--text`) | Body, logo, nav, toggle icon |
| Muted | `#5c6570` (`--muted`) | Footer, equal diff lines (~5.5:1 on `#f4f6f8`) |
| Border | `#d5dbe3` (`--border`) | Hairlines on the light canvas |
| Grid line | `rgba(15, 23, 32, 0.10)` (`--grid-line`) | Same 47/48 geometry; slightly stronger than research `0.08` so the grid reads on `#f4f6f8` |
| Diff add | fg `#0f7a45` / bg `#e7f7ee` | Add hunks remain green, not dark-theme `#13291f` |
| Diff del | fg `#b42318` | Delete hunks remain red on the light canvas |

Shared non-color tokens stay on `:root` only (do not duplicate under light): `--mono`, `--sans`, `--content: 52rem`.

`color-scheme: dark` on `:root`. `color-scheme: light` on `:root[data-theme="light"]`. Never `color-scheme: light dark`. Do not add `<meta name="color-scheme">`.

QR module paints stay `#ffffff` / `#000000` in `QrCode.tsx` — **not** theme tokens. Do not open that file.

Accent reserved for:

- In-page text links (`a { color: var(--accent) }`)
- `.nav-links a:hover`
- `:focus-visible` 2px outline on `a` and `button` (existing HEAD rule — toggle inherits it)
- Existing `.tool-panel button` border + text (do not restyle this phase)

Accent is **not** for: page canvas, panels, body grid, toggle default icon color (use `--text`), QR modules, diff hunks, danger errors, borders.

Do not add overlay-only tokens (`--led`, `--accent-dim`, `--bg-elev` as a real token, `--radius`, `--display`). Leave `.md-preview code` / `pre` on `var(--bg-elev, var(--panel))`.

## Copywriting Contract

HEAD chrome is English-only. Do not add `ui.ts` keys. The toggle has no visible caption.

| Element | Copy |
|---------|------|
| Primary CTA | `Toggle color theme` — `aria-label` on `#themeToggle` only. Verb + noun. No `Dark mode`, no `Switch theme`, no ZH string. |
| Empty state heading | none — theme is never an empty collection. First visit with no `localStorage` still paints light or dark from `prefers-color-scheme` before first paint. |
| Empty state body | none — do not render “No theme selected”, a placeholder icon, or a tooltip. |
| Error state | none shown. `localStorage` `getItem`/`setItem` failures are `try/catch` swallowed. The document still gets `data-theme="light"` or `"dark"`. Do not toast, inline alert, or `role="alert"` for storage errors. |
| Destructive confirmation | none — toggling theme is not destructive; no confirm dialog. |

Do not change Tools / Blog / About labels or `href`s. Do not add `aria-pressed` or a visually hidden “currently light/dark” string (not locked; keep the control to one label).

## ThemeInit

New file `src/components/ThemeInit.astro`. Render as the **first child of `<head>`** in HEAD `BaseLayout.astro` (before `<meta charset>`).

- `<script is:inline>` IIFE only. No frontmatter logic, no imports, no `src/lib/theme.ts`.
- `try { t = localStorage.getItem('theme') } catch (e) {}`
- Allowlist: use storage only when `t === 'light' || t === 'dark'`. Anything else (missing, `null`, `"undefined"`, junk) falls through to `matchMedia('(prefers-color-scheme: dark)')` → `'dark'` if matches, else `'light'`.
- Always `document.documentElement.setAttribute('data-theme', t)` with those two literals.
- **Do not** `setItem` here. First visit must keep following OS until the user clicks.
- **Do not** listen to `matchMedia('change')`.
- SSG HTML has no `data-theme`. Dark CSS on `:root` is the fallback if the script is blocked.

### Click script

In `ThemeToggle.astro`, `<script is:inline>`:

- `document.getElementById('themeToggle')?.addEventListener('click', …)`
- `next = el.getAttribute('data-theme') === 'light' ? 'dark' : 'light'`
- `el.setAttribute('data-theme', next)`
- `try { localStorage.setItem('theme', next) } catch (e) {}`
- One instance per page. Do not put init logic in this script.

## Interaction contract

| Moment | What the visitor sees |
|--------|------------------------|
| First visit, OS dark, empty storage | Dark canvas + sun icon. No flash of light. Storage still empty. |
| First visit, OS light, empty storage | Light canvas + moon icon. No flash of dark. Storage still empty. |
| Click toggle | Attribute flips immediately; icon flips; `localStorage.theme` becomes `'light'` or `'dark'`. |
| Hard refresh after a click | Stored theme paints before first paint. OS changes do not override. |
| Navigate `/` → `/tools/` → `/about/` | Same stored theme. Header toggle present on every BaseLayout page. |
| Storage blocked | Attribute still set from matchMedia (init) or from the click `next` value. No error copy. |
| ThemeInit blocked / throws | No `data-theme`. `:root` dark tokens. Sun icon (moon stays `display: none`). Site matches HEAD. |

No theme transition animation (`transition` on `background` / `color` is out of scope). No three-state `auto`.
